Phraseology the pilots understand

Start with the callsign (FIN321 or Finnair three two one; GA Echo Sierra Alpha Bravo Charlie, abbreviated Echo Bravo Charlie after first contact). Several instructions can go in one transmission.

DeliveryFIN321 cleared to Helsinki via flight planned route, climb 5000 feet, squawk 4201, contact Ground 131.905
PushFIN321 push and start approved, facing east
TaxiFIN321 taxi to holding point runway 26 via S A · cross runway 08 · hold position · continue taxi · hold short of runway 08 · apron lane names work in "via" too
TowerFIN321 runway 26 line up and wait · runway 26 cleared for takeoff · contact Tallinn Radar 127.905
ArrivalsFIN321 identified, descend 3000 feet, cleared ILS approach runway 26 · contact Tower 135.905 · runway 26 cleared to land · go around · taxi to stand K2 via B A
FixesFIN321 negative, squawk 4201 · information Bravo is current · if you read, squawk ident · affirm
Radio failure (RCF, squawk 7600)The aircraft cannot hear or answer you — only squawk ident shows on the label. Use the light gun (ICAO Annex 2): on the ground FIN321 light green flashing = cleared to taxi (and to cross the next runway when holding short), light green steady = cleared for takeoff, light red steady = stop, light red flashing = clear the landing area, light white flashing = return to your starting point. In the air light green steady = cleared to land, light green flashing = return for landing, light red steady = give way / go around and continue circling, light red flashing = do not land. FIN321 send follow-me dispatches the follow-me car, which leads the aircraft to its stand and asks you for runway crossings (Follow-me 1 cross runway 08). The buttons in the aircraft panel do the same.

EuroScope as your radar

  1. Keep python server.py running (FSD on 127.0.0.1:6809).
  2. EuroScope → Connect. Connect type Direct to VATSIM, untick "Connect to VATSIM", Server 127.0.0.1.
  3. Any callsign (e.g. EETN_TWR), any CID/password; load a sector file for the airport.
  4. Prime the tower frequency (e.g. 135.905) in the voice/frequency dialog. Text you send on that frequency (or privately to a pilot) is handled exactly like typing here.
